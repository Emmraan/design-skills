# Example Site — Design Analysis

> Complete this file after a Dembrandt extraction (see `scripts/analyze-agent.md`).
> Follow the DESIGN.md-compatible structure. Describe **design decisions**, not pixels.

## 1. Visual Theme & Atmosphere
- Mood / personality / design philosophy of the site.

## 2. Color Palette & Roles
- Semantic name + role (primary / neutral / surface / accent / text). Note contrast logic, not just hex values.
- Dark/light handling.

## 3. Typography Rules
- Families, pairing logic, hierarchy table (display / headings / body / labels), scale relationship, measure, line-height.

## 4. Component Stylings
- Buttons (primary/secondary/tertiary states), cards, inputs, navigation, badges, links — with states.

## 5. Layout Principles
- Spacing scale/rhythm, grid, whitespace philosophy, section rhythm.

## 6. Depth & Elevation
- Shadow system, surface hierarchy, borders.

## 7. Do's and Don'ts
- Guardrails this site follows; anti-patterns it avoids.

## 8. Responsive Behavior
- Breakpoints, collapse strategy, touch targets.

## 9. Agent Prompt Guide
- Quick reference + ready-to-use prompt that captures this site's design language.

---

## Extended (synthesis-focused, keep these — they drive originality)

### 10. Component Map
- Ordered list of sections (hero → logo cloud → features → …) with one-line notes on each.

### 11. Pattern Position
- Which industry pattern this site best fits; what makes its page flow effective.

### 12. Synthesis Notes
- What is **unique** here (worth borrowing as logic).
- What to **combine** with other references to create an original design.
- Weaknesses / what to avoid copying.
