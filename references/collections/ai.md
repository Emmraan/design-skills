# Collection: AI

The AI category is flooded with lookalike "purple gradient + floating orbs" pages. This
collection points to the repo references that show how to make an AI product feel **real,
honest, and differentiated** — the demo is the hero, the trust story is the moat.

## Category definition

AI-powered tools and features. Buyers are skeptical: they've been oversold. The page must
show the AI working, set expectations, and answer data/privacy objections — see
`patterns/ai-product.md` for assembly.

## Synthesis guidance

- Avoid the AI clichés: purple-blue gradients everywhere, orb animations, "the future is
  here" copy.
- Lead with a real output artifact (chart, summary, code diff) or a live demo — not a
  screenshot of a cherry-picked answer.
- Include a data/privacy answer; radical honesty ("best for X, not Y") is a brand.
- If everyone is dark-first, try light/editorial — an instant differentiator.
