# Collection: Developer Tools

Devtool buyers decide in the terminal, not the hero. This collection maps the repo's
developer-tools references: pages that convert on copy-paste and keep trust with docs.

## Category definition

CLIs, SDKs, agent skills, APIs, and dev infrastructure. Goal: install → first success
in minutes → docs depth → changelog proof the project is alive. The install command
is a component, not a code sample.

## Synthesis guidance

- The install command is the primary CTA — design it like a terminal card with a copy
  button, never as plain text.
- Docs must outweigh the landing; a dead changelog kills devtool trust.
- One accent color, disciplined placement; mono for all code, sans for voice.
- Answer "does it still work / is it maintained" above the fold (stars, changelog,
  version).
